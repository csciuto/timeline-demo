# The Year Room (repo: timeline-demo)

Static site, no build step for the page. Served at corey.sciu.to/timeline-demo/ by GitHub Pages from
`.github/workflows/deploy.yml` (runs unit/data tests, stamps `const VERSION = 'dev'` in js/app.js).

- Content lives in `data/items.txt`; `data/years.json` is generated by `python3 scripts/build_data.py` and committed.
  Never hand-edit years.json. Rebuild after any items.txt change; the data test fails if they're out of sync.
- Scope: an American room, "what's in the room that year" (not strictly released that year). One `hit` per year
  (Billboard year-end No. 1) except the last year.
- Facts: every item names a Wikipedia article; the build verifies the intro mentions the year ±1. Don't add to
  `data/checked.txt` without actually confirming the fact.
- Images are hotlinked from Wikimedia: free ones credited (author · license), non-free shown small with a © note.
  Nothing is downloaded into the repo.
- Tests: `npm test` (node --test + python unittest), `npm run test:e2e` (Playwright, Wikimedia and fonts blocked),
  `npm run screenshot` for preview.png. Needs PATH=/opt/homebrew/bin for node.
